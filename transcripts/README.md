# Executed transcripts

These JSON files are generated by `python part4_demo.py`. Running `python scripts/verify_offline.py --evidence` regenerates them with external network access blocked and measured (local loopback is permitted for test infrastructure). They contain real framework outputs under the deterministic mock provider, rather than hand-written expected answers.

| File | Demonstration |
|---|---|
| `crew_tools.json` | Policy question invoking RAG, order question invoking lookup, and mixed question invoking both |
| `memory.json` | Same-session order follow-up, separate fresh session without the order, and explicit reset |
| `guardrails_and_budget.json` | Phone/card-last-4 masking, injection refusal, unrelated-question groundedness refusal, unsupported-claim refusal, and oversized request rejection |
| `autogen_reviews.json` | Both reviewer messages and structured verdict for unchanged approval and a deliberately corrupted draft revised on another query |
| `least_autonomy.json` | Attempt to wire the lookup tool to the Composer blocked by the capability guard |
| `cache.json` | Before/after search and generation counters for a normalized repeated query |
| `api.json` | HTTP response, WebSocket conversation, fresh connection after disconnect, sanitized per-request logs and API assertions |

Trace IDs and timings vary across runs. `reports/acceptance.json` contains the executed assertions; `reports/evaluation.json` contains all 15 judged responses and per-property reasons. The only PII examples used by the generator/tests are fabricated; generated request text is already masked.
