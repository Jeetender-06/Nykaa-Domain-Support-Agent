# Return window by product category

Apparel and Footwear returns are accepted within 7 calendar days of delivery when the item is unworn and its tags remain attached.
Home items have a 7 calendar day return window when unused and in their original packaging.
Beauty products can be returned within 5 calendar days only if unopened with the hygiene seal intact; opened cosmetics are not eligible for a change-of-mind return.
Electronics have a 7 calendar day return window for a verified defect, with the invoice, accessories, and original packaging required.
